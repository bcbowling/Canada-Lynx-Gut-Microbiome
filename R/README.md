This is a folder for all R code

## Clean Up 
Order for fastq file clean up and prep
1. install_packages.R (install any missing packages)
2. clean_fastq.R (clean up data and create sequence table)
3. taxonomy_training.R (format taxonomy training file)
4. assign_taxonomy.R (create taxonomy table)
5. phylo_tree.R (create phylogenetic tree)
6. create_phyloseq.R (combine data into phyloseq object for analysis)
